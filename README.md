# Morphological, molecular, and biological characterization of *Monalonion dissimulatum* Distant associated with cacao in Amazonas, Peru

## Description 

This repository contains the curated dataset and analysis code supporting the study of *Monalonion dissimulatum* associated with cacao (*Theobroma cacao* L.) in Amazonas, Peru. The study integrates field assessments, morphological characterization, DNA barcoding analyses, and biological observations to describe the species, its incidence, and its life cycle under natural conditions.

## Data and files

- **`dataframe.xlsx`** — Curated dataset containing sampling-site information, incidence records, nymphal and adult morphometric measurements, and developmental-stage duration data. The same dataset is accessible through Google Sheets.
- **`analysis.qmd`** — Analysis code used to generate the descriptive statistics and visualizations.
- **`figures.zip`** — Original photographs and micrographs used to prepare the composite figures presented in the manuscript. These image files are archived in Zenodo.

## Supplementary information

The original data underlying the reported results are provided in Supplementary Tables S1–S4 (Supplementary Material S1), while the COI sequence alignment used for phylogenetic reconstruction is provided in Supplementary Material S2.

The COI sequences generated in this study have been deposited in [GenBank](https://www.ncbi.nlm.nih.gov/nuccore/) under accession numbers PX954299, PX954300, and PX954301.
